## 实现范围

- `BulletSweep.cs`：线段与扩张 AABB 的连续 slab 查询，4×4px 子弹，双精度命中时间；从起点到整段终点查找，非仅检查帧末位置。
- `MapState.BlocksBullet()`：单独定义子弹阻挡，读取现有4px砖墙残存位；砖、钢阻挡，水 / 草 / 冰不阻挡。地图边界单独处理，不复用坦克的水面阻挡规则。
- `BulletWorld.Step(map, targets)`：先收集本 tick 所有候选，再按连续命中时间全局结算。先发生的接触优先；相同时间按边界→地形→基地→坦克→子弹，再按目标稳定 ID、子弹租约 ID 排序。对单颗子弹这等价于最早命中距离；不同速度的子弹按同一 tick 的时间比例比较，不错误比较各自移动距离。
- 地形使用4px damage-cell行主序 ID；边界 ID 为左1、下2、右3、上4；基地 / 坦克由调用方提供唯一稳定 EntityId。对子弹对碰，以后生成一颗的 Id 为目标 Id，再以先生成一颗的 Id 排序，三弹同刻相遇结果确定。
- 每颗子弹每 tick 最多消费一次。更早命中墙 / 目标的子弹不再参与之后的对子弹碰撞；失效的对子弹候选也不会遮蔽另一颗子弹稍后的合法命中。所有候选处理完才回收对象，避免复用对象改变当前结算。
- 新增共享 `CombatTeam`、`BulletTarget`（逻辑矩形快照）、不可变 `BulletHit`。子弹不打自身 / 友方坦克；敌方坦克可命中；基地无论射手阵营均可命中。同阵营子弹穿过，敌对子弹通过相对运动扫掠互相消耗，支持迎面与垂直交叉。
- 目标矩形取坦克移动完成后的静态快照。本批不实现坦克与子弹的相对移动扫掠，符合既定更新顺序。
- 命中记录保留原 BulletId、OwnerId、阵营、方向、命中中心、tick 时间比例、目标 ID、地形种类与4px格坐标；对子弹记录另一弹 Id 和同刻位置。回收 / 复用后记录不变。
- `Hits` 只表示最近一次逻辑 tick；下一 tick 清空，显式 `Clear()` 也清空。后续伤害 / 破墙 / 特效应在同一逻辑 Step 中消费事件，不在渲染帧末读取并期待保留全部中间 tick。
- 首次进入盒体即消费，包括正好在 tick 终点接触。平行擦边、仅碰角而不进入、从接触面背离不算命中。炮口已经在墙内时 t=0 消费；不把子弹继续向墙后移动。
- `ArenaSession` 已传入唯一 MapState，并用实际玩家16×16px矩形更新玩家目标快照；玩家武器使用稳定实体 Id=1。
